Six Ways to Use the Scanline API Key

Your sl_live_* key authenticates every request to the Scanline REST API.

01

Single Image Forensic Scan

Submit any JPG, PNG, or WEBP image to POST /v1/scan and receive a full forensic verdict — ELA score, FFT noise, facial symmetry — within 200ms.

02

PDF Forensic Report Generation

Append generate_pdf_report=true to any scan request. Receive a secure, signed PDF audit certificate with SHA-256 hash, UUID, and ELA heatmap.

03

Batch Queue Processing

Send up to 20 images per request to POST /v1/batch. Results are returned as a JSON array, sorted by synthetic probability score.

04

Webhook Alerts on Detection

Register a webhook_url in your API key settings. Scanline will POST an alert payload to your endpoint whenever a synthetic image exceeds your configured threshold.

05

Audit History Export

Pull your full scan history from GET /v1/history. Responses include timestamps, verdicts, confidence scores, and links to stored PDF reports for compliance audits.

06

Model Benchmark & Metadata

Query GET /v1/models to retrieve accuracy benchmarks, latency figures, and supported generator fingerprints (Midjourney, FLUX, SDXL, DALL·E 3) for your current API tier.

All API requests require Authorization: Bearer <your_key>. Rate limit: 500 requests/day on the free tier.
